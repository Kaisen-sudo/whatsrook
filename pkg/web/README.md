# WhatsRook Web Session Generator

A zero-dependency, lightweight static web tool for generating encrypted WhatsRook session tokens directly in the browser using the native Web Cryptography (`AES-GCM`) and `CompressionStream` APIs.

## Features

- **Zero dependencies**: Pure HTML5, CSS3, and modern vanilla JavaScript. No Node.js, Bun, or build tooling required.
- **Privacy-first**: All session token encryption and compression happen entirely client-side in the browser. No data is sent over the network.
- **Hosted on GitHub Pages**: Deployed directly from this folder.
